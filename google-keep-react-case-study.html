Project Deep Dive

Google Keep React

Recreating the Google Keep experience in React with a polished note-taking interface, custom enhancements, and responsive design.

Project Brief

This assignment challenged me to step into the role of a junior intern at Google and build a Google Keep-inspired app that feels polished, functional, and user-friendly. The goal was to recreate the core experience of Google Keep while adding thoughtful improvements that make the project feel more complete and modern.

The brief focused on building a strong base experience first, then extending it with creative features that demonstrate both technical ability and design thinking.

What I Set Out to Build

Core requirements:

  • A clean Google Keep-style homepage layout
  • A note creation area with add and delete actions
  • A masonry-style notes grid that feels familiar and intuitive
  • A responsive design that works well on both desktop and mobile

Enhanced features:

  • Custom note organization with color-coding and pinning
  • A search bar to help users quickly find notes
  • Dark mode for a more modern and accessible experience
  • Reminder-style functionality to make notes more useful

How I Approached the Build

I structured the app around reusable React components so the interface could stay organized and easy to scale. The experience was built with a simple but effective flow: users can create notes, view them in a visually appealing grid, and manage them without confusion.

I focused on building the app in a way that feels familiar to Google Keep users while still showing my own style and design decisions. The layout was kept clean, and the interactions were designed to feel smooth and lightweight.

Technical Choices

Technology Stack:

  • React for component-based UI development
  • CSS for layout, styling, and responsive behavior
  • Local storage for saving notes between refreshes
  • Reusable state logic for adding, editing, deleting, and searching notes

Design and UX Focus:

  • Clean note cards with strong visual hierarchy
  • Responsive spacing for smaller screens
  • Clear actions for creating and managing notes
  • Simple interactions that support a smooth everyday workflow

What Made This Project Valuable

This project helped me strengthen my understanding of React in a practical, real-world way. It pushed me to think about component structure, user experience, and how to create interfaces that feel simple but still have depth.

I also learned how important it is to balance visual design with function. A beautiful interface is not enough on its own; it has to support clear actions and make note-taking feel effortless.

Challenges and Learning

  • Managing note state clearly across multiple interactions
  • Keeping the layout responsive without losing visual balance
  • Making the experience feel polished rather than overly complicated
  • Designing features that improve the app without making it cluttered

What I Would Improve Next

If I were to continue developing this project, I would add more advanced note features such as editing existing notes, drag-and-drop reordering, richer reminder logic, and better filtering options. I would also refine the UI further to make the experience even closer to a production-level note app.

Outcome

This case study reflects a React-based Google Keep concept that combines the assignment brief, practical UI design, and a thoughtful approach to user experience. It shows how a simple note-taking app can become much more engaging when its structure, styling, and features are carefully considered.
