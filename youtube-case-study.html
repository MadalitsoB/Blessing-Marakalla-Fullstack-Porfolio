Project Deep Dive

YouTube Clone

Building a functional YouTube prototype using HTML, CSS, and Vanilla JavaScript.

Executive Summary

This project is a front-end web application that replicates the core user interface and interactive features of YouTube. Built using vanilla HTML, CSS, and JavaScript, it demonstrates practical web development skills including responsive design, DOM manipulation, state management, and user experience considerations.

Project Overview

Objective: To create a functional prototype of YouTube's user interface with core interactive features, providing an educational demonstration of modern web development practices without relying on frameworks.

Technology Stack:

  • HTML5: Semantic markup and structure
  • CSS3: Responsive design, flexbox layout, theme switching
  • JavaScript (Vanilla): DOM manipulation, event handling, local storage management

Key Deliverables:

  • Responsive navigation bar with search functionality
  • Collapsible sidebar with subscription management
  • Video grid with hover previews
  • Video modal with playback capabilities
  • Dark/Light theme toggle
  • Mobile-responsive design

Technical Architecture

User Interface Components

Navigation Bar:

  • YouTube logo with branding
  • Real-time search bar with filtering capabilities
  • Action buttons for create, notifications, theme toggle, and profile
  • Sticky positioning to remain visible during scroll
  • Responsive design with icons showing/hiding based on screen size

Sidebar Navigation:

  • Navigation sections for Home and Shorts
  • Subscriptions section with channel links and custom icons
  • Hamburger menu for mobile screens
  • Active state indicators for current section

Video Grid:

  • Video cards displaying thumbnail, title, channel, and stats
  • Interactive hover overlays with action buttons
  • Click-to-play modal functionality
  • Responsive layout adapting from 1 to 6+ columns based on screen size

JavaScript Functionality

Sidebar Toggle (Mobile): Event listeners for menu button clicks toggle the sidebar active state, with auto-close on main content click for smaller screens.

Search & Filter System: Real-time filtering by title and channel name with case-insensitive matching and dynamic card visibility updates on keyup events for immediate feedback.

Theme Management: User preferences saved to localStorage with support for light and dark modes, persisting across browser sessions using data-theme attributes.

Video Modal System: Parses YouTube URLs to extract video IDs, handles multiple video sources (YouTube embeds, local files, fallbacks), and supports keyboard shortcuts like ESC to close.

Video Preview Overlay: Dynamically created hover overlays displaying title, channel, and action buttons for an interactive user experience without page reloads.

Responsive Design

Breakpoints:

  • Mobile: ≤ 768px
  • Tablet: 768px - 1024px
  • Desktop: > 1024px

Adaptive Features:

  • Sidebar collapses to mobile menu below 768px
  • Search bar becomes icon-only on small screens
  • Video grid reduces columns on smaller devices
  • Touch-friendly button sizes
  • Flexible navigation bar layout

User Experience Considerations

Accessibility:

  • Semantic HTML structure (header, aside, main)
  • ARIA labels for buttons
  • Keyboard shortcuts (ESC key support)
  • Alt text for all images

Performance Optimizations:

  • Vanilla JavaScript with no framework overhead
  • Event delegation where applicable
  • Efficient DOM queries with querySelector
  • Considerations for lazy loading images

User Feedback:

  • Visual hover states on interactive elements
  • Active indicators for selected filters
  • Modal overlay for focused content viewing
  • Smooth transitions for theme switching

What I Would Do Differently

If I were to build this again, I would:

  • Implement infinite scroll or pagination for better performance with large video lists
  • Add more advanced filtering options (by upload date, duration, views)
  • Create a more robust state management system for handling complex interactions
  • Implement animation transitions for better visual feedback
  • Add user account features with profile customization
  • Integrate with real YouTube API for live data
