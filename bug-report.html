IHUB Prototype Bug Report

This report documents the QA findings for the IHUB prototype, including major HTML, navigation, script, and asset issues.

1. Major HTML structure bug in index.html

  • The homepage section id="journey" / .timeline block is malformed.
  • The fifth .t-step item does not close before the next <section class="carousel-section"> begins.
  • Missing closures:
    • </div> for the last timeline step
    • </div> for .timeline
  • The section id="journey" block is incorrectly nested, causing unpredictable browser DOM autocorrection and layout/accessibility issues.

2. Mobile navigation problem on about.html and contact.html

  • Both pages include .nav-links but omit the mobile menu checkbox (<input id="navCheck">) and the hamburger toggle (.nav-toggle).
  • The responsive CSS at @media (max-width: 880px) hides .nav-links by default and only reveals them when navCheck is checked.
  • On tablet/phone widths, the menu is likely hidden and cannot be opened on those pages.
  • programme.html and index.html are not affected because they include the mobile menu markup.

3. Interactive functionality is missing

  • The site includes interactive elements such as carousel controls and modal triggers with data-modal-open / data-modal-close.
  • scripts.js is empty, so these behaviors are not implemented.
  • As a result:
    • Carousel controls will not work.
    • Modals will not open or close.
    • Any JavaScript-based enhancements are non-functional.

4. Asset path risk

  • index.html references an image with spaces and commas in the filename:
  • ./assets/300673_6c38f9845d8d8533bb6d7e2dacb4a291-6_18_2026, 3_14_48 AM.png
  • This may work in some browsers but is fragile and can fail on certain servers or reference patterns.

5. Responsiveness assessment

  • Page layout is generally responsive with good mobile breakpoints.
  • Responsive behavior is described correctly for hero sections, stacked cards, timeline layout, and form/carousel adaptations.
  • However, actual experience is not fully correct on all pages because:
    • index.html / programme.html likely work on laptop/tablet/phone aside from the malformed timeline and missing JS.
    • about.html and contact.html likely break on tablet/phone due to inaccessible mobile navigation.

Summary

  • Critical bug: malformed HTML in index.html timeline/carousel area.
  • Important functional bug: empty scripts.js prevents carousel and modal interactions.
  • Significant responsive bug: missing mobile nav toggle on about.html and contact.html.
  • Visual layout is mostly responsive, but these issues prevent a clean multi-device experience.
